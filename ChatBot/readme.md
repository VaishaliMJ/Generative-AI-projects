##  👩‍💼💻🤖 ChatBot  :  Using LangGraph
### Overview 
This project is as text based **ChatBot**.It accepts ths user query using a text box. Sends that query to the locally running **Llama3 Large language model(LLM) through Ollama**,receives intelligent answer and stores chat history as well.

#### 🎯 Main Objective
  The main objective of this project is to build a ChatBot which will answer the user queries .The project helps understand
*  Generative AI
*  AI Agents
*  LLM Integration
*  Prompt Engineering
*  LangChain and LangGraph
  
#### 🔑 Key Features:
*	**Interactive UI**     :  Its a Streamlit based web application for user query.
*	**Evaluation By LLM**  :  Integrated Large Language Models (LLMs) to analyze question-by-question responses, and provide answer to                              the user
*	**Chat History**       :  Maintained user chat history using SQLLite 
* **Generative AI**      :  Applied concepts of Generative AI, Prompt Engineering, AI Agents,LangChain,LangGraph and conversational                               intelligence to simulate real time chat history.

## 🚀 Getting Started
### Pre-requistic
Ensure you have the following libraries installed on your local machine:
  *	langgraph
  *  langchain
  *  python-dotenv
  *  langchain-ollama
  *  streamlit
  *  langgraph-checkpoint-sqlite

### Project Flow
*  User types the query in text box and hits enter
*  Later on question it sent to locally running Llama3 for answer
*  Evaluation result is generated by Llamma3 and gets displyed on screen 
*  Answer is streamed word by word as it gets generated
*  On completion of chat user can start new conversation thread
*  Old conversation threads are also available on side panel
